# Оформление репозитория на GitHub

Заполняется на странице репозитория: шестерёнка рядом с **About** справа.

## Description

```
17 бесплатных инструментов для YouTube в одном месте: скачать видео и MP3, субтитры и теги, розыгрыш по комментариям, редактор Shorts, превью, плейлисты. Без API-ключей и регистрации. FastAPI + yt-dlp + ffmpeg, ванильный JS.
```
