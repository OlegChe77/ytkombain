# YouTube Комбайн — концепция продукта

Документ фиксирует решения, принятые до написания кода: продукт, UX, визуальный язык и SEO-архитектуру.

## 1. Продукт

**Для кого.** Авторы каналов и их помощники, SMM-специалисты, организаторы розыгрышей, студенты и все, кому
нужно быстро что-то «достать» из YouTube: файл, текст, картинку, список, ссылку.

**Главная работа продукта.** Человек приходит с уже скопированной ссылкой. Самый короткий путь к результату —
вставить её один раз и сразу увидеть, что с ней можно сделать. Поэтому центр продукта — не каталог, а поле
«Что вы хотите сделать с YouTube?», которое распознаёт тип ссылки и предлагает подходящие инструменты.

**Сценарии.**

| Сценарий | Путь |
|---|---|
| Скачать ролик | Вставить ссылку на главной → «Скачать видео» → выбрать качество → файл |
| Розыгрыш на стриме | «Выбрать победителя» → загрузить комментарии → условия → барабан → «На весь экран» |
| Shorts из ролика | «Редактор Shorts» → отрезок ползунками → 9:16 с размытым фоном → титры и музыка → MP4 |
| Конспект лекции | «Субтитры» → язык → поиск по тексту → TXT |
| Курс на YouTube | «Длительность плейлиста» → диапазон уроков → скорость 1,5× → дни |
| Оформление канала | «Аватар и шапка» → исходные файлы → ID и RSS |

**Категории (дорожки).** Видео, Комментарии, Изображения, Ссылки, Плейлисты — 17 инструментов.
Каждый инструмент — отдельная страница с собственным URL, но ссылка, введённая один раз, передаётся
между инструментами (`?url=` и память сессии), чтобы не вставлять её заново.

## 2. Визуальные направления

Рассматривались три варианта:

1. **«Монтажный стол».** Интерфейс монтажной программы: нейтральный графит, дорожки таймлайна,
   воспроизводящая головка, клипы разных цветов. Прямо связано с видео и с «обработкой» контента.
2. **«Контактный лист».** Светлый стол фотографа, кадры плёнки с номерами, пометки восковым карандашом.
   Красиво, но больше про фотографию, чем про скорость и инструменты.
3. **«Цех».** Индустриальная эстетика комбайна: сигнальный жёлтый, таблички, заклёпки.
   Запоминается, но легко скатывается в пародию и утомляет в ежедневной работе.

**Выбран первый**, усиленный вторым источником из мира видео — **телевизионной настроечной таблицей**.
Её цветные полосы стали цветами пяти категорий-дорожек, а логотип — кнопкой «play», сложенной из этих полос.
Красный YouTube сознательно не используется.

**Одна смелая деталь** — таймлайн в hero: это одновременно визуальный образ и меню. Клипы на дорожках —
настоящие ссылки на инструменты; когда пользователь вставляет ссылку, неподходящие клипы гаснут.
Единственная «сцена» анимации — проход головки по дорожкам при загрузке. Всё остальное спокойное.

**Токены.**

| Роль | Тёмная тема | Светлая тема |
|---|---|---|
| Фон | `#1b1c21` графит монтажки | `#f3f4f6` дневной монитор |
| Панель | `#24252c` | `#ffffff` |
| Текст | `#eeeef0` | `#17181c` |
| Видео | `#7482ff` | `#4f5cf0` |
| Комментарии | `#e46fd5` | `#b43ba4` |
| Изображения | `#f1c84b` (и головка таймлайна) | `#a87c00` |
| Ссылки | `#43c9e3` | `#0a84a3` |
| Плейлисты | `#4fcf87` | `#1b8c4f` |

Основные кнопки монохромные (инверсия фона) — цвет остаётся за категориями.

**Шрифт.** Geologica — одна вариативная гарнитура с кириллицей. Заголовки используют ось остроты `SHRP`:
буквы получают «срезы», как лезвия комбайна или монтажные склейки. Текст — та же гарнитура без остроты.
Цифры везде табличные — важно для таймкодов и размеров файлов.

**Радиусы по иерархии:** 5 px — клипы, 9 px — кнопки, 13 px — поля, 20 px — панели.

## 3. Мобильный UX

- Нижняя панель с главным действием «Вставить ссылку» (читает буфер обмена и открывает палитру с подходящими
  инструментами) — пользователь чаще всего приходит из приложения YouTube с уже скопированной ссылкой.
- Выдвижное меню с категориями вместо мега-меню.
- Таймлайн на телефоне скрыт, его роль выполняют дорожки категорий ниже.
- Таблицы превращаются в карточки, панели настроек встают над результатом, у кода и превью встраивания — вкладки.
- Кнопка «Выбрать победителей» прилипает к низу экрана, поля ввода 16 px (без автозума в iOS), зоны нажатия от 44 px.

## 4. SEO-архитектура

- Плоские адреса инструментов: `/youtube-downloader`, `/youtube-comment-picker` и т. д.; категории — `/category/<slug>`.
- У каждой страницы уникальные Title, Description, H1, OG-картинка и FAQ; `canonical`, Open Graph и Twitter Card.
- JSON-LD: `WebSite` и `ItemList` на главной, `WebApplication` + `BreadcrumbList` + `FAQPage` на инструментах,
  `BreadcrumbList` + `ItemList` на категориях.
- Хлебные крошки «Главная → Категория → Инструмент», перелинковка «Пригодится дальше».
- Текст на каждой странице отвечает на реальные вопросы: как пользоваться, ограничения, частые ошибки.
- `sitemap.xml`, `robots.txt` (закрыт `/api/`), `manifest.webmanifest`, favicon во всех размерах.
- Всё содержимое рендерится на сервере — поисковик видит страницу без выполнения JavaScript.
