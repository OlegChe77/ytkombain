Какие ссылки собирает Комбайн

Для видео

Короткую youtu.be, полную, мобильную, ссылку для YouTube Music, адрес для встраивания, вариант без cookies, обычную ссылку вместо Shorts и прямые адреса превью.

Для плейлиста

Страницу плейлиста, запуск первого видео с автопереходом к следующим, адрес для встраивания и RSS-ленту новых видео.

Для канала

Постоянную ссылку по ID, ссылку на подписку, вкладки видео и Shorts, RSS-ленту. Для @имени Комбайн сначала определит ID канала — это займёт пару секунд.

Видео в ссылку для просмотра — как поделиться роликом

Для мессенджеров и соцсетей удобнее всего короткая ссылка youtu.be: она занимает одну строку, аккуратно выглядит в сообщении и открывает то же видео — в приложении YouTube на телефоне или в браузере на компьютере. Если смотреть нужно не с начала, соберите ссылку с таймкодом.

Как пользоваться

  1. Вставьте любую ссылку YouTube — тип определится автоматически.
  2. Выберите нужный вариант и нажмите «Копировать».

Совет

Ссылку на подписку удобно ставить в конце описания и в соцсетях: она сразу открывает окно подтверждения, и зрителю не нужно искать кнопку.
